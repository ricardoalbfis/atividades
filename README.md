# Portfólio — Relatividade Geral

Repositório com as atividades desenvolvidas na disciplina, organizadas para acompanhamento.

📄 **Portfólio online:** https://SEU-USUARIO.github.io/NOME-DO-REPO

## Estrutura

- `notebooks/` — cadernos Jupyter (deduções, cálculos com SymPy, testes numéricos)
- `simulacoes/` — apps Streamlit e scripts de simulação
- `docs_pdf/` — listas, relatórios e seminários em PDF
- `docs/` — código-fonte da página do portfólio (GitHub Pages)

## Como atualizar

```bash
git add .
git commit -m "descrição do que foi adicionado"
git push
```

A página e o app Streamlit se atualizam automaticamente após o push.
